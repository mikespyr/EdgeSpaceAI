# EdgeSpace AI Flutter app

Dark smart-building UI matching the supplied EdgeSpace AI mockup, with:
- dashboard
- buildings and rooms
- room live status
- interactive charts
- analytics filters and comparisons
- AI assistant
- alerts
- sensor/device health
- BLE + QR onboarding
- Wi-Fi provisioning
- demo and real-backend modes

Run `bootstrap_platforms.ps1` once if Android/iOS folders do not exist, then apply `PLATFORM_PERMISSIONS.md`.
